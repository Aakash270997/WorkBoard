# WorkBoard - MERN Project Management Dashboard

WorkBoard is a full-stack project management application build to demonstrate practical skills in React, TypeScript, Node.js, Express and MongoB.

## Planned Features
- user authentication and protected routes
- Crreate, read, update, and delete tasks
- Task status management
- Search, filtering, and pagination
- Responsive user interface
- REST API with validation and error handling
- Automated tests and deployment

## Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS

**Backend:** Node.js, Express, TypeScript

**Database:** MongoDB, Mongoose

**Tools:** Git, GitHub, Postman

## Project Structure

- `client/` - Frontend application
- `server/` - Backend API

## Development Roadmap

1. Project setup and UI foundation
2. Backend and database integration
3. Authentication and task management
4. Testing, optimization, and deployment
